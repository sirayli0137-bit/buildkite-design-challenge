Deck 3

Design Exploration

From V2 to V7. Each option tested a question — not proposed a solution.

Methodology

  1. State the question the variant tests
  2. Build it
  3. Identify what works + what fails
  4. Synthesise the next variant from what I keep + what I drop

The final architecture (V7) is the synthesis, not the first idea.

Five turning points

Decisions where the iteration shifted direction.

1Why don't all step links look the same? · Three patterns (chip/border, text+arrow, icon+name) became one (icon+name, no arrow, hover affordance)
2Why is the action far from the trigger? · Preview fix top-right; disclosure expanded bottom-left. Diagonal eye-track. Moved trigger near the disclosure.
3Suggestion + AI explanation: two things or one? · Same content at different lengths. Merged into one disclosure.
4Should AI be loud on the surface? · Initially yes (Sparkles + "Show more AI explanation" + "Preview AI fix"). Stripped back; AI source acknowledged inside the card only.
5Pipeline shape: strip or bar? · Tried both visible. Redundant. Strip wins in expanded view; bar stays for collapsed Tier 1.

The pattern dispatch refactor

Mid-iteration: three string-matching lookups had grown brittle.

function getSuggestion() { if (exit === 1 && isTest) return "..."; ... }

const aiExplanation = (() => {
  if (suggestion?.includes("CommonJS")) return "...";
  ...
})();

const fixPreview = (() => { ... if (suggestion?.includes("CommonJS")) ... })();

Refactored to a typed pattern table:

const failurePatterns: FailurePattern[] = [
  { id, matches: predicate, suggestion, explanation, fix },
  ...
];

One entry per pattern. Suggestion + explanation + fix coupled by typed identity, not string content.

What this delivered

  • Five visual variants before the right one
  • Five scenario variants to pressure-test it
  • One refactor that future-proofs the architecture

Most decisions came from rejecting alternatives, not from the first idea.
