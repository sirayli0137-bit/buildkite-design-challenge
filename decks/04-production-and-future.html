Visual rules

Two type sizes only · 14px max

  • text-sm (14px) — body, headings
  • text-xs (12px) — meta, buttons, labels
  • font-mono — exit codes, durations only

Highlight only the highest-value signals

  • Highlighted — red AlertCircle, semibold failure name, exit code badge
  • Plain neutral — duration, parent step, matrix context, flaky text

Affordance vocabulary maps to commitment level

  • Outlined buttons → reversible (Retry, Preview fix)
  • Solid black → only Apply fix
  • Ghost buttons → soft actions (Copy summary)
  • Inline text links → content disclosure (Show more explanation)

Architecture

Typed pattern dispatch

const failurePatterns: FailurePattern[] = [
  { id: "commonjs-esm-mismatch", matches: ..., suggestion, explanation, fix },
  { id: "eslint-violations",     matches: ..., suggestion, explanation, fix },
  { id: "oom-kill",              matches: (_, exit) => exit === 137, ... },
];

One entry per pattern. Suggestion + explanation + fix coupled by typed identity.

Scenario data — single source of truth

App.tsx's getScenarioForVariant() picks the right dataset, so the whole build header (collapsed bar AND expanded panel) reflects the scenario.

Accessibility wins

  • WCAG AA contrast (zinc-500 minimum on white)
  • Status icons paired with aria-label on links — SR hears "Test matrix, Failed"
  • Copy summary state change announced via visually-hidden aria-live="polite"
  • All disclosure triggers carry aria-expanded
  • Decorative icons consistently aria-hidden="true"
  • Focus-visible rings on every interactive element
  • Semantic HTML: <nav><ol> for the strip, real <button> / <a> distinguished
  • Status communicated via icon + text label, never colour alone

Trade-offs & deferred work

Conscious trade-offs

  • AI labelling: implicit on surface, explicit inside disclosure
  • Per-row Copy summary: granular sharing vs slight redundancy
  • Pipeline strip vs progress bar: strip wins in expanded view

Out-of-scope per PRD §12.2

  • Real telemetry (flaky count, typical duration, cross-build count are mocked)
  • Real AI service integration (pattern dispatch is the contract)
  • Inline log preview (lives in Tier 3)
  • Cross-build aggregation as a separate surface (V7.5 is the entry only)
